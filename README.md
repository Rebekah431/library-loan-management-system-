# Library Loan Management System

## Overview
A console-based application for managing book loans, members, and records using file-based storage.

## Features
- View available books
- View members
- Loan books to members
- Return books
- Track active loans

## Technologies
- Python
- File handling (text files)

## How to Run
1. Ensure Python is installed
2. Run:
   python main.py

## Key Learning
- File I/O operations
- Input validation and error handling
- Modular programming
- Data processing and storage
